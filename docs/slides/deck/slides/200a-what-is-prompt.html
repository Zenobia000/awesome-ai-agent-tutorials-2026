Prompt 是什麼

Prompt（提示詞）＝交給模型的那份交辦單。模型不變，交辦單一換，它做的事就跟著換。

像交辦工作給一位新同事
交辦單
你的角色是…
背景資料是…
要做到…不准…
照這個範例交
很聰明，但不知道
你公司的任何事
同一個模型，換一張交辦單就換一份工作：
「翻成英文」
「三句話摘要」
「轉成 SQL」
權重一個都沒動，不用重新訓練
你可能已經見過
在 ChatGPT、Claude 對話框打的每一句話
「自訂指令」「專案說明」：每次對話前自動附上的那張交辦單
程式呼叫 API 時，messages 裡的 system 與 user 內容
交辦單補不了的
它不知道的資料，寫得再好也變不出來 → RAG（模組三）
要它每次都照固定格式交 → 結構化輸出（本章後半）
