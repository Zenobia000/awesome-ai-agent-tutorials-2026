選型：結構化輸出工具

三種機制：事後驗證重試、伺服器端約束、逐 token 遮罩。格式能保證，內容仍要自己驗。

名稱機制什麼時候選它
Pydantic本課用github.com/pydantic/pydantic只定義 schema 與驗證，不負責生成所有方案的共同底層
服務商原生（OpenAI、Claude、Gemini）developers.openai.com原生 JSON Schema，伺服器端約束用雲端 API；Gemini 只支援 schema 子集
Ollama format本課用docs.ollama.comAPI 直接吃 JSON Schema本機 Lab
LangChain with_structured_outputdocs.langchain.com包一層，自動選原生或工具呼叫換模型不想改程式；agent 用 response_format
Instructorpython.useinstructor.com提示＋Pydantic 驗證＋失敗重試只做資料萃取、要跨服務商
Outlines／vLLM／llama.cppdottxt-ai.github.io約束解碼：每個 token 都被遮罩自架模型，要保證格式
舊教學常見的 vLLM guided_json 參數已移除，現在叫 structured_outputs。　核實 2026-11-17
