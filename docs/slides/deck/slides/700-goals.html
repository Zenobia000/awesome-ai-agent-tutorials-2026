MCP 與低代碼

心法：工具用一個協定接進來；固定流程交給低代碼，要自己決定下一步的留給程式碼。

學習目標

  • 說出 MCP 解決什麼：N × M 個接頭，降成 N + M 個
  • 畫出 Host／Client／Server，講得清 Tools、Resources、Prompts 各由誰決定何時用
  • 分得清 stdio 與 Streamable HTTP，知道各自用在哪
  • 用官方 SDK 寫出 MCP Server，接進 Cherry Studio 與 Dify
  • 劃出 Dify／n8n 與 LangGraph 的邊界
本章實戰　Lab7 Excel 自動分析智能體：使用者丟進一份 Excel，模型透過 MCP 呼叫本地工具，完成清洗、統計、畫圖，再寫出分析結論。
