Reducer：同時寫入怎麼合併

預設是覆蓋；想合併，就在欄位上明講「怎麼合併」。

預設：覆蓋
加 reducer：追加
search_web
search_db
["web"]
["db"]
results
["db"]
只留最後寫的值
search_web
search_db
["web"]
["db"]
results
["web", "db"]
兩個值都留下來
class State(TypedDict): results: list
class State(TypedDict): results: Annotated[list, operator.add]
先後執行的兩個節點，是後者覆蓋前者；若同一步並行寫入，LangGraph 乾脆拋 InvalidUpdateError。
messages 欄位請用內建的 add_messages（可依訊息 id 更新）。
你已經會的PyTorch 的 .grad 預設累加（所以每步要 zero_grad）；LangGraph 相反：預設覆蓋，要累加得明講。
怎麼讀：兩個三角是並行的工具節點，都要寫同一個欄位；左邊只留一個值，右邊靠 operator.add 把兩個值接在一起。
