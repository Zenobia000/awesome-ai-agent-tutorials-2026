LLM 把文字變成三元組

三元組＝（主詞, 關係, 受詞）。每段文字交給 LLM 抽一次，抽完寫進圖。

文字片段
韓立出身七玄門，
後來進入黃楓谷；
他隨身帶著掌天瓶。
限定類型
LLM
三元組（主詞, 關係, 受詞）
(韓立, MEMBER_OF, 七玄門)
(韓立, MEMBER_OF, 黃楓谷)
(韓立, OWNS, 掌天瓶)
Neo4j
節點＋有型別的邊
你已經會的限定可抽的類型，就是把開放式生成變成「固定類別的分類」，錯得比較少。
from langchain_neo4j import LLMGraphTransformer # 新路徑 transformer = LLMGraphTransformer( llm=llm, allowed_nodes=["Person", "Sect", "Treasure"], allowed_relationships=["MEMBER_OF", "OWNS"]) graph_docs = transformer.convert_to_graph_documents(docs)
怎麼讀：由左往右：文字進圓（LLM），出來三元組，再寫進圖；程式碼就是中間那顆圓。
