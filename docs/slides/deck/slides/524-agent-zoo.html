一個場景一個 agent：智能體動物園

請假、報銷、訂票、合約……各自一套提示詞、工具、部署，場景一多就維護不動。本課轉述

做法：每個場景各做一個專用 agent
請假 agent
報銷 agent
訂票 agent
合約 agent
客服 agent
週報 agent
每個籠子：圓＝模型，方＝提示詞，三角＝工具。每一個都要單獨維護。
維護起來會怎樣
同一個修正，要在每個 agent 各改一次
共用的規範（格式、權限、語氣）被複製貼上，慢慢走樣
場景一多，誰來決定把請求交給哪個 agent，又成了新問題
下一頁：一個通用 agent，把場景知識做成可插拔的 Skills
怎麼讀：每個虛線籠子是一個專用 agent；左邊是這種做法，右邊是它帶來的維護成本。
