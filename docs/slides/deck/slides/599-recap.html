模組 5 小結

  • Agent＝模型＋工具＋記憶＋迴圈。tool calling 是模型產生 JSON，真正執行的是你的程式。
  • LangGraph 把迴圈畫成狀態圖：State、Node、Edge；多個節點寫同一欄位要靠 reducer。
  • Checkpointer 每步存檔：記憶、時光旅行、人在回路（interrupt → resume）都靠它。
  • 多智能體：子 agent 包成工具，只傳請求、只回摘要；代價是 token。
  • recursion_limit 預設 10,007 不是保險：明確設小，再加次數上限。
