你可能已經用過 Agent

先看四類常見產品：你交給它一句話，它自己做了哪些事。

寫程式
Claude Code、Cursor、Codex
你說
「把這個測試修到會過」
它自己
讀程式碼 → 改檔 → 跑測試 → 沒過再改
做研究
ChatGPT、Gemini 的 Deep Research
你說
「比較三套向量資料庫」
它自己
搜尋 → 讀網頁 → 發現缺口再搜 → 寫成附出處的報告
操作瀏覽器
ChatGPT agent、Manus
你說
「找下週飛東京最便宜的票」
它自己
開網站 → 填表單 → 比價 → 付款前停下來問你
自動化流程
Dify、n8n 的畫布流程
你畫好
收信 → 分類 → 回覆
它照著跑
步驟是人排好的，模型只負責其中幾格
共同點：你給的是目標，不是步驟——下一步由它自己決定
對照組：步驟由人決定
怎麼讀：前三類每一步做什麼是模型自己挑的；最右邊的流程是人排好的。這個差別就是下一頁的定義。
