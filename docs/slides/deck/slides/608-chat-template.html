chat template：把對話排成 token 序列

模型只會接續 token。模板規定角色標記和結束符怎麼擺，訓練和推理必須用同一套。

[ {"role": "system", "content": "你是問診助理"}, {"role": "user", "content": "最近一直頭痛"}, {"role": "assistant", "content": "頭痛幾天了？"} ]
套模板
<|im_start|>system 你是問診助理<|im_end|> <|im_start|>user 最近一直頭痛<|im_end|> <|im_start|>assistant 頭痛幾天了？<|im_end|>
Qwen 系列的模板。Mistral 用 [INST]，Zephyr 用 <|user|>，各家不同，不能混用。
模型實際看到的 token 序列
system、user、assistant 開頭標記
不算 loss
回答＋結束符，算 loss
結束符讓它學會「在這裡停」
模板和基座不符時的真實症狀
loss 照樣下降，看不出問題
推理時停不下來
重複輸出、角色錯亂
你已經會的灰色那段就是語意分割裡的 ignore_index=255：不參與 loss；特殊 token 像類別編碼規範，兩端要一致。
怎麼讀：先看上排：messages 變成帶標記的字串；再看中間的方塊列：只有朱紅色的回答部分被拿來算 loss。
