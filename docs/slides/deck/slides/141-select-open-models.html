選型：開放權重模型家族

權重下載到自己機器上跑。「開源」不等於隨便商用：同一家族，大小尺寸的授權可能不同。

家族／廠商定位什麼時候選它授權（看 LICENSE 原文）
Qwen（阿里巴巴）本課用huggingface.co/Qwen尺寸最齊、中文強本地小模型、中文、要微調中小尺寸 Apache-2.0；最大旗艦另有自訂授權
DeepSeekhuggingface.co/deepseek-ai大型 MoE、授權寬要寬鬆授權的前沿級權重MIT（自架硬體門檻高）
Gemma（Google）huggingface.co/google手機到單卡的小模型筆電、邊緣裝置、單張消費級 GPUGemma 4 為 Apache-2.0
gpt-oss（OpenAI）huggingface.co/openaiOpenAI 的開放推理模型要 OpenAI 系權重做推理、agentApache-2.0；須用 harmony 格式
Mistraldocs.mistral.ai歐洲系，尺寸分層小尺寸要 Apache、歐盟合規考量小尺寸 Apache-2.0；Large 做 API 服務要另簽約
Llama（Meta）huggingface.co/meta-llama舊生態大既有 Llama 生態或教材相容自訂社群授權，有用戶數門檻與標示要求
其他常見：GLM（智譜）、Kimi（Moonshot）——MIT 式授權但附營收門檻。Meta 2026 年的新開放模型改叫 Muse Glimmer（Apache-2.0）。　核實 2026-11-17
怎麼讀：先用第三欄挑家族，再一定要看第四欄：要商用或對外提供服務，授權要看到「你用的那個尺寸」。
