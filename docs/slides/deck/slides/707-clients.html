客戶端：設定一次，接任何 Server

本機 Server 填一行指令，遠端 Server 填一個網址；客戶端自己去問它有什麼能力。

Claude Desktop 的設定檔 claude_desktop_config.json
{ "mcpServers": { "filesystem": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/you/Desktop"] } } }
顯示名稱：自己取
command + args：Host 替你在終端機下的那行指令，
像用 torchrun 啟動訓練腳本時傳的參數
官方 Filesystem Server 的套件名
允許它碰的資料夾：要寫絕對路徑
Cherry Studio：Settings → MCP → MCP Servers
新增 Server
本機填 command；遠端填 URL（Streamable HTTP）
啟用並檢查
狀態正常，且看得到它的 tools、resources、prompts
