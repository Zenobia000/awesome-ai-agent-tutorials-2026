條件邊：讓流程有分岔

條件邊就是路由：一個普通函式讀 state，回傳「下一個節點叫什麼名字」。

START
call_model
route(state)
run_tool
run_tool
END
有 tool_calls
沒有 → 結束
工具跑完，回到模型
def route(state: MessagesState): last = state["messages"][-1] if last.tool_calls: return "run_tool" return END g.add_conditional_edges( "call_model", route, ["run_tool", END]) g.add_edge("run_tool", "call_model")
對照 505：手寫迴圈裡的 if not msg.tool_calls，現在變成圖上的一條邊。
MessagesState 內建 messages 欄位（下一頁說它怎麼合併）。
實線＝固定邊
虛線＝條件邊，由 route 決定走哪條
你已經會的early-exit 網路、MoE 的 gating 同理：依輸入決定走哪條路；router 只是普通函式。
怎麼讀：菱形是路由函式：有 tool_calls 就走上面去呼叫工具，沒有就走下面結束；工具跑完固定回到模型。
