文字進模型前，先切成 token

token ＝ 詞表裡的一個單位，可能是一個詞、半個詞或一個字。每個 token 對應一個整數 id，模型只看得到 id。

中文　今天天氣真好，適合出門散步。
11 個 token
英文　The weather is great today, perfect for a walk.
11 個 token

切分結果來自 Qwen3 的 tokenizer（id 為實際查表值；英文 token 前面其實帶一個空白，圖中省略）。「天氣」被切成「天」「氣」兩塊——詞表不必認得每個詞，認得更小的零件就拼得出來。不同模型的 tokenizer 切法不同，費用與 context 用量都按 token 數計。

怎麼讀：上排是原句切成的方塊，方塊下面的數字是它在詞表裡的 id；模型的輸入就是這一串整數。
