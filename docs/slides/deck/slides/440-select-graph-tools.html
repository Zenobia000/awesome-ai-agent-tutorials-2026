選型：圖資料庫與 GraphRAG 工具

分兩層看：底下存圖的資料庫，上面負責「建圖＋檢索」的套件。授權差很多，商用前先看清楚。

名稱是什麼什麼時候選它授權／狀態
Neo4j本課用neo4j.comLPG 圖資料庫，Cypher 查詢要成熟的圖 DB、教材多Community 為 GPLv3；Enterprise 需商業合約
LLMGraphTransformer本課用github.com/langchain-ai/langchain-neo4jLangChain 的抽圖工具已用 LangChain，快速把文件轉成圖MIT；從 langchain_neo4j 匯入
neo4j-graphrag-pythonneo4j.comNeo4j 官方建圖＋檢索要消歧、Text2Cypher、混合檢索Apache-2.0；建圖管線仍標實驗性
Microsoft GraphRAGgithub.com/microsoft/graphrag社群報告派的研究實作研究、重現 Global／Local 查詢MIT；維護模式，不加新功能
LightRAGgithub.com/HKUDS/LightRAG輕量 KG-RAG要比 MS GraphRAG 便宜、多種查詢模式MIT；server 預設不開認證
Memgraphmemgraph.com記憶體內圖 DB，相容 Cypher要低延遲即時查詢、沿用 Neo4j 驅動BSL 1.1，非 OSI 開源
另外：FalkorDB（Redis 模組，SSPLv1）；Kùzu 已在 2025-10 封存，舊教材推薦它的要拿掉。　核實 2026-11-17
怎麼讀：紅字兩列是本課 Lab 4 的組合；要商用或對外提供服務，最右欄的授權比效能更先決定。
