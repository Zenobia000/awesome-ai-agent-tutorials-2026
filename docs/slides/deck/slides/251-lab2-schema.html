一個 Pydantic 類別，兩頭都用

一頭產生 schema 約束模型，另一頭驗證模型交回的文字。

class SQLGenerationResult(BaseModel): sql: str # 單一 SELECT tables: list[str] # 用到的資料表 risk: Literal["low", "medium", "high"] explanation: str # 邏輯解釋 resp = chat( model="qwen3:14b", messages=messages, format=SQLGenerationResult.model_json_schema(), ) result = SQLGenerationResult.model_validate_json( resp.message.content)
risk 是模型自評
拿來參考可以，不能當安全閘門
出：schema 交給模型
解碼時被約束，輸出必須長這樣
入：文字變成物件
不合格就丟 ValidationError
這裡用本地 Ollama 的寫法（format 參數傳 JSON Schema）；OpenAI、Anthropic 的 SDK 可以直接吃 Pydantic 類別。
怎麼讀：由上往下。黃底兩行是 Pydantic 的兩頭：先產出 schema 約束模型，再驗證模型交回的文字；朱紅底是不能信的欄位。
