Lab 6：用 LLaMA-Factory 做問診風格 LoRA

一個 yaml 決定一次微調；兩個數字照常用值：r = 8，alpha = 16。

clinic_lora.yaml
model_name_or_path: Qwen/Qwen3-8B do_train: true # 沒寫就只評估、不訓練 finetuning_type: lora lora_rank: 8 # r lora_alpha: 16 # 一般取 rank × 2 lora_target: all # 所有線性層都加 dataset: clinic_sharegpt # 要先註冊，見下頁 template: qwen3 # 必須和基座對應 learning_rate: 1.0e-4 num_train_epochs: 3.0 val_size: 0.1 eval_strategy: epoch # 每個 epoch 評估一次 logging_steps: 10 # 每 10 步記一次 loss output_dir: saves/qwen3-8b/lora/clinic
資料問診／客服風格 JSON（ShareGPT 格式）
訓練Qwen3-8B 凍結，只訓練旁路 A、B（RTX 4090）
llamafactory-cli train clinic_lora.yaml
檢查點adapter：只含 A、B 的小檔案
匯出與驗證併回原精度基座，載入前後對話比身份標籤和專業話術
怎麼讀：左邊是這次微調的全部設定，高亮三行是重點；右邊是它跑出來的四步，每一步產出什麼。
