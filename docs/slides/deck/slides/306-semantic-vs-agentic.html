名字像，做法不同。semantic chunking 只用 embedding 算距離，不用 LLM；agentic chunking 才讓 LLM 讀文字做判斷。

Semantic chunking：用距離找切點
不用 LLM。embedding 模型給每句一個向量，比相鄰兩句。
Agentic chunking：讓 LLM 判斷
沒有標準 API；每句都要呼叫 LLM，成本高。
