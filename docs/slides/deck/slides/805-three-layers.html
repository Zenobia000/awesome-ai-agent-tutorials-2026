AI 產業三層：你站在哪一層

這是本課自己整理的分法；重點是站在 API 之上，又看得懂下面的模型。本課整理

第三層　AI 產品使用者
用現成產品，主要靠寫提示詞
第二層　AI 產品製造與全棧應用層
做出能上線的產品：prompt、RAG、agent，加上產品自己的資料與評測
第一層　基礎模型層
算力、框架、基座模型研發：預訓練、通用 benchmark
API 線
AI 工程師站這層
在 API 之上做產品，擁有產品自己的資料與評測，不必自己訓練基礎模型。
你的差異化
懂反向傳播與微調（模組六），能從這層往下延伸。
「API 線」的說法出自 swyx 的〈The Rise of the AI Engineer〉；三層的切法是本課整理，不是業界共識。
怎麼讀：上下三格是三層；虛線是 API 線，線下是模型廠商，線上是你做產品的地方，箭頭是你往下延伸的能力。
