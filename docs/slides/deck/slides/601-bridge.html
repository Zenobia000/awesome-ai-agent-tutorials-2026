遷移學習你做過，微調是同一件事

預訓練模型是現成的特徵提取器。幾種做法的差別，只在「動哪些權重」。

你在視覺任務做過的
權重怎麼動（藍凍結、朱紅更新）
對應到 LLM（本章）
特徵提取凍結 backbone，只拿特徵給外接分類器
Prompt、RAG模型一個參數都不動，只改輸入
只換 FC 頭凍結 backbone，訓練新的輸出層
只訓練輸出層其餘凍結（LLM 的輸出頭就是詞表 softmax）
解凍全部層所有層一起微調
全量微調所有權重都更新，顯存和資料要求最高
視覺裡沒有的第四種這就是本章要學的
LoRA全部層都動，但每層只動一點點
你已經會的遷移學習的核心動作是「決定凍結誰、更新誰」。LLM 沒有換頭這回事，選擇題變成：動哪些層、每層動多少。
怎麼讀：每一列是一種做法：左邊是你熟悉的名字，中間是權重的狀態，右邊是它在 LLM 裡的樣子；最後一列是新的。
