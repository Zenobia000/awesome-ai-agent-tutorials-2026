50 行手寫 agent 的解剖

核心迴圈只有十幾行；加上 client 與工具定義，整份約 50 行（Lab5-A）。

messages = [{"role": "user", "content": question}] for _ in range(MAX_STEPS): resp = client.chat.completions.create( model=MODEL, messages=messages, tools=TOOLS) msg = resp.choices[0].message messages.append(msg) if not msg.tool_calls: return msg.content for call in msg.tool_calls: args = json.loads(call.function.arguments) out = REGISTRY[call.function.name](**args) messages.append({"role": "tool", "tool_call_id": call.id, "content": str(out)})
messages：這次對話的全部記憶
迴圈；MAX_STEPS 是保險絲
呼叫模型：整串 messages＋工具清單一起送
這一輪的回覆也存進 messages
終止條件：沒要工具＝說完了，回傳答案
解析 arguments（JSON 字串）→ 真的執行 → 結果以 role: tool 追加，下一圈模型就讀得到
你已經會的迴圈＝訓練迴圈的 for step in range(...)；messages 清單＝迴圈裡一路累積的狀態。
怎麼讀：左邊是程式，右邊是每一段在做什麼；方、圓、三角和全 deck 同義；菱形是「這一圈要不要結束」的判斷。
