Lab 4：一次多跳提問怎麼跑

模型只負責兩頭：抽出角色名、組織答案。中間的 Cypher 是寫好的模板。

提問
抽出角色
Cypher 多跳
格式化成上下文
回答
「和韓立同門派的人，
還有誰？」
["韓立"]
把名字填進模板，
唯讀執行
七玄門的成員：
韓立、厲飛雨、墨大夫
韓立的同門有
厲飛雨、墨大夫。
實際執行的 Cypher（結果為示意）
MATCH (h:Person {name: $name})-[:MEMBER_OF]->(s:Sect) <-[:MEMBER_OF]-(p:Person) RETURN s.name AS sect, p.name AS peer // → 七玄門 | 厲飛雨 // → 七玄門 | 墨大夫
你已經會的模組二的 Text2SQL 讓模型寫整句 SQL；這裡只讓模型抽名字，Cypher 是固定模板，更好驗證、更可控。
怎麼讀：由左往右：圓是 LLM，三角是工具動作（跑 Cypher），方塊是資料；程式碼對應中間的三角。
