MCP 是什麼

MCP＝AI 應用接外部工具的標準接頭：工具做一次接頭，各家 AI 應用都能插。

像 AI 的 USB-C
AI 應用
Claude Desktop、
Cursor…
MCP
本機檔案
GitHub
行事曆
資料庫
每個工具都長同一種插頭：做一次，哪個 AI 應用都能接。
你可能已經見過
Claude Desktop、Cursor 設定裡的「新增 MCP server」
讓 AI 讀你的本機檔案、GitHub、行事曆
工具廠商公告：「我們提供 MCP server」
MCP 做不到的
不會讓模型變聰明，只是把接頭統一
插上的工具能動你的資料 → 權限與信任要自己管
怎麼讀：左邊的應用只有一個 MCP 接口；右邊每個工具都用同一種插頭（小方塊）接上來。
