踩坑：Server 連不上的三種原因

三個坑都出在 Host 與 Server 之間那條線上。

症狀
原因
修法
一連上就斷
Host 報連線逾時或解析錯誤，工具清單載不出來
stdio Server 用 print() 往 stdout 寫字，把 JSON-RPC 訊息切壞了——stdout 是協定專用管線
除錯訊息改用 logging（寫 stderr）；Server 程式裡不留任何 print()
Dify 連不到本機 Server
連線被拒，或連到的是容器自己
容器裡的 localhost 指的是容器自己；而且 Dify 只接 HTTP 傳輸，不接 stdio
Server 改走 Streamable HTTP；網址用 host.docker.internal（Linux 要另設 extra_hosts）
設定好了卻逾時
Server 起不來，Host 一直在等
Host 啟動子行程時，沒帶你終端機的 PATH 與環境變數；相對路徑也失效
command 與路徑寫絕對路徑；環境變數放進設定檔的 env；查看 mcp-server-*.log
怎麼讀：每一列是一個坑，由左往右：看到什麼 → 為什麼 → 怎麼修。
