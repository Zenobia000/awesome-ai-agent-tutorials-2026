Lab 5-C：兩個子 agent 掛上 Supervisor

子 agent 已包成 schedule_event、manage_email；Supervisor 只拿這兩個工具。

supervisor = create_agent( model, tools=[schedule_event, manage_email], system_prompt=( "你是個人助理。需求拆成排程與郵件兩類，" "分別交給對應工具，最後統整回覆。"), checkpointer=InMemorySaver(), # 只有最上層掛 ) supervisor.invoke( {"messages": [{"role": "user", "content": "週二下午跟 Ann 開會，並寄議程給她"}]}, {"configurable": {"thread_id": "u1"}})
執行時 Supervisor 看到的 示意
supervisor → schedule_event "週二下午跟 Ann 開會" ← "已排週二 15:00–16:00" supervisor → manage_email "寄議程給 Ann，說明週二 15:00 開會" ← "已寄出" supervisor → 使用者 "會議排好了，議程也寄給 Ann 了。"
子 agent 若掛 HumanInTheLoopMiddleware，寄信前一樣要過審批；checkpointer 只掛最上層。
怎麼讀：左邊是組裝 Supervisor 的全部程式；右邊是它執行時的 trace，每個子 agent 只剩一問一答。
