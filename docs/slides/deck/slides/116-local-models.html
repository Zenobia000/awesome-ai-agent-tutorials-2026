依顯存挑本地模型

模型檔要放得進顯存，還得留空間給 context。本地版預設是 4-bit 量化，檔案小、品質略降。

4-bit 量化
每個權重從 16 bit 壓成 4 bit，檔案大幅縮小，品質略降。
ollama pull qwen3.5:9b # 對話模型，16 GB 顯存可跑 ollama pull deepseek-r1:8b # 現在指向 R1-0528-Qwen3-8B ollama pull nomic-embed-text # 嵌入模型，模組三會用 # 要原版 Llama distill：deepseek-r1:8b-llama-distill-q4_K_M
怎麼讀：長條是模型檔案大小，虛線是 16 GB 顯存（課綱的單卡條件）。檔案要遠小於顯存，因為 context 也要佔位置。
