選型：Embedding 與重排模型

中文語料先確認模型支援中文；要自架就挑開放權重，不想維運就用 API。

模型用途取得方式／授權中文什麼時候選它
bge-m3（BAAI）本課用huggingface.co/BAAIEmbedding開放權重／MIT強本地、多語；一個模型出稠密＋稀疏
bge-reranker-v2-m3本課用huggingface.co/BAAI重排開放權重／Apache-2.0支援本地、多語精排
Qwen3-Embedding／Rerankerhuggingface.co/Qwen兩者都有開放權重／Apache-2.0強有 GPU、要長文與更強精排
nomic-embed-text v1.5huggingface.co/nomic-aiEmbedding開放權重／Apache-2.0只有英文Ollama 跑英文語料；要加前綴
OpenAI text-embedding-3developers.openai.comEmbeddingAPI支援已用 OpenAI、不想自架
Cohere Embed／Rerankdocs.cohere.com兩者都有API支援要託管的多語重排
小心授權：Jina 的開放權重多為 CC-BY-NC-4.0（不能商用）。Embedding 換模型，整座向量庫都要重建。　核實 2026-11-17
怎麼讀：中文語料先看第四欄排除不支援的，再依「自架或 API」挑；紅字是本課 Lab 用的組合。
