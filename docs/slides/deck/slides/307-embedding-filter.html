向量檢索：先過濾，再比距離

embedding 把每個片段變成空間裡的一個點，問題也變成一個點；意思越近，距離越近。ChromaDB 還能先用 metadata 篩掉不要的版本。

向量空間示意實際有上千維，這裡壓成 2 維畫
metadata：附在每個片段上的標籤，例如版本、模組名稱、章節。
維度由 embedding 模型決定；bge-m3 是 1024 維。
你已經會的embedding＝預訓練 encoder 抽出的特徵向量；先過濾再比距離＝先套 mask，再做最近鄰搜尋。
# 先用 where 過濾，再比距離取前 5 col.query( query_embeddings=q_vec, n_results=5, where={"version": "v2"}, )
怎麼讀：灰色打叉的點被 where 條件擋掉，不參加比距離；紅色虛線圈是剩下的點裡離問題最近的 5 個。
