傳輸：本機走 stdio，遠端走 HTTP

同一份 JSON-RPC 訊息，可以走兩種管道；舊的 HTTP+SSE 已被取代。

stdio　本機子行程

像 subprocess.Popen 的 stdin／stdout 管線
Host
MCP Server子行程
stdin：請求
stdout：回覆
stdout 只放協定訊息，別 print()
stderr：除錯訊息寫這裡

Streamable HTTP　遠端

像呼叫一個推論 API：每則訊息一個 HTTP POST
Client
遠端 ServerHTTP 服務
POST /mcp
回傳 JSON，或 SSE 串流
SSE 只是回覆的一種格式（邊做邊回報進度），不再是獨立的傳輸。
