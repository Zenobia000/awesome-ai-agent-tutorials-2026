只從舊存檔重跑、不改 state，叫 replay；改了 state 才叫 fork。
history = list(app.get_state_history(cfg)) past = next(s for s in history if s.next == ("write_joke",)) fork = app.update_state( past.config, {"topic": "chickens"}) app.invoke(None, fork)
history 由新到舊。s.next 是「下一個要跑的節點」，用它找出想回到的那一步。
示意　topic、write_joke 取自官方文件的例子。
你已經會的載入第 5 個 epoch 的 checkpoint、改學習率、開一條新實驗：同一件事。
怎麼讀：上排是原本跑過的路；從 c2 往下長出的下排是改了 state 的新路，兩條各自保留。
