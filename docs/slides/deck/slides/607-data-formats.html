兩種都要在 dataset_info.json 登記，formatting 欄填 alpaca 或 sharegpt，訓練時用名字指到它。
真正餵給模型的不是這份 JSON，而是套完 chat template 的 token 序列（下一頁）。
你已經會的ImageFolder 和 COCO 標註：存檔格式不同，最後都轉成 (x, y) 張量。
怎麼讀：兩張卡片是同一段問診的兩種寫法；Alpaca 把歷史放進 history，ShareGPT 直接把輪次排成 conversations 陣列。
