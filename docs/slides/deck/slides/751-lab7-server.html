Lab7 關鍵程式：函式簽名就是工具定義

官方 SDK 讀你的型別註記與 docstring，自動產生模型看得到的工具說明。

server.py
from mcp.server import MCPServer import pandas as pd mcp = MCPServer("excel-analyst") @mcp.tool() def describe_excel(path: str) -> str: """讀取 Excel，回傳欄位名稱與前五列。""" return pd.read_excel(path).head().to_string() if __name__ == "__main__": mcp.run(transport="stdio")
SDK 自動
轉成工具定義
模型看到的 tools/list 項目 示意
{ "name": "describe_excel", "description": "讀取 Excel，回傳欄位名稱與前五列。", "inputSchema": { "type": "object", "properties": {"path": {"type": "string"}}, "required": ["path"] } }
別在 stdio Server 裡 print()：stdout 是協定專用管線，要記錄就用 logging（寫 stderr）。
改成 HTTP 給 Dify 接（埠號以實際為準）：
uv run mcp run server.py --transport streamable-http # Dify 填入：http://host.docker.internal:8000/mcp
怎麼讀：左邊是你寫的函式，右邊是模型實際看到的說明；Server 的程式不變，只換傳輸。
