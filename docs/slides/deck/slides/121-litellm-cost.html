一個介面接所有家，帳單都算 token

LiteLLM 把各家 API 統一成 OpenAI 格式；不管接哪一家，費用都是 token 數乘上單價。

LiteLLM：一個 completion() 接所有供應商
from litellm import completion, completion_cost, Router r = completion(model="ollama/qwen3:14b", messages=m) # 換一家只換前綴：openai/… openrouter/… anthropic/… cost = completion_cost(completion_response=r) router = Router(model_list=[ {"model_name": "local", "litellm_params": {"model": "ollama/qwen3:14b"}}, {"model_name": "cloud", "litellm_params": {"model": "openrouter/…"}}, ], fallbacks=[{"local": ["cloud"]}]) router.completion(model="local", messages=m)
前綴決定送去哪家，回應一律是 OpenAI 格式。CrewAI 早期底層就用它；1.x 起常見供應商改走原生 SDK，LiteLLM 變成選裝的備援。
