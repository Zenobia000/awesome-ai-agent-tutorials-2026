Lab 3 程式：切分並寫入本地 Chroma

先依標題切片，再把片段、metadata 和向量一起存進本地持久化的 Chroma。

01　依標題切分
02　寫入 Chroma
from langchain_text_splitters import ( MarkdownHeaderTextSplitter, ) splitter = MarkdownHeaderTextSplitter( headers_to_split_on=[ ("#", "h1"), ("##", "h2"), ("###", "h3"), ], strip_headers=False, # 標題留在內文 ) md = open("whitepaper.md").read() chunks = splitter.split_text(md)
import chromadb from sentence_transformers import SentenceTransformer model = SentenceTransformer("BAAI/bge-m3") client = chromadb.PersistentClient(path="./chroma_db") col = client.get_or_create_collection("whitepaper") texts = [c.page_content for c in chunks] ids = [f"c{i}" for i in range(len(texts))] text = dict(zip(ids, texts)) # id → 內文，查詢要用 metas = [{**c.metadata, "version": "v2"} for c in chunks] col.upsert( ids=ids, documents=texts, metadatas=metas, embeddings=model.encode(texts).tolist(), )
strip_headers=False 讓標題進內文；version 寫進 metadata，之後才能用 where 過濾；重跑用 upsert，同 id 才會被覆寫（add 會靜默略過）。
怎麼讀：左邊切片，右邊存庫；黃色那兩行是這個 Lab 最容易漏掉的設定。
