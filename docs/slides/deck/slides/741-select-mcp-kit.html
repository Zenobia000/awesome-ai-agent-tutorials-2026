選型：寫 MCP、測 MCP、用 MCP

寫 Server 用 SDK，測試用 Inspector，最後接到你平常用的客戶端。

名稱是什麼什麼時候用注意
官方 Python SDK（mcp）本課用github.com/modelcontextprotocol/python-sdk官方 SDK寫 Server／Client 的預設選擇v2 起高階類別 FastMCP 改名為 MCPServer
FastMCP（獨立版）gofastmcp.comPrefect 維護的高階框架要代理、組合多個 Server 等進階功能和官方 SDK 內的同名類別是兩回事
MCP Inspectorgithub.com/modelcontextprotocol/inspector官方除錯工具寫完 Server 先在這裡點工具測試npx 直接跑，不用安裝
Claude Desktop、Claude Code、Cursor、VS Codemodelcontextprotocol.io常見的 Host日常寫程式、桌面助理裡直接用工具專案層級設定檔可進版控，團隊共用
Cherry Studio本課用cherryai.com桌面 LLM 客戶端本課 Lab 7 跑通本機 stdio要綁到 Agent 才用得到；AGPL-3.0
官方 MCP Registry 仍是 preview，只收 Server 的中繼資料；MCP 自 2025-12 起由 Linux Foundation 旗下的 Agentic AI Foundation 治理。　核實 2026-11-17
怎麼讀：由上往下是開發順序：先用 SDK 寫，用 Inspector 測，再接進下面的客戶端。
