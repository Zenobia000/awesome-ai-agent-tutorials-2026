選型：本地推理與服務

個人跑模型和給一群人用，是兩種需求：前者求方便，後者求吞吐量。

工具定位什麼時候選它授權／狀態
Ollama本課用github.com/ollama/ollama一行指令跑本地模型課堂 demo、個人開發；有 OpenAI 相容 /v1MIT
llama.cppgithub.com/ggml-org/llama.cppC/C++ 推理、GGUF 量化CPU、Mac、邊緣裝置；Ollama 的底層MIT；1.0 版移除舊 C API
LM Studiolmstudio.ai圖形介面的本地模型 App不想碰命令列的桌機使用者App 為閉源；CLI lms 為 MIT
vLLMgithub.com/vllm-project/vllm高吞吐 GPU 服務引擎上線、多人同時呼叫Apache-2.0
SGLanggithub.com/sgl-project/sglang高效能 LLM／多模態服務多輪、共用前綴多、大型 MoEApache-2.0
TGI不推薦github.com/huggingface/text-generation-inferenceHugging Face 舊推理伺服器不建議新專案；官方建議改用 vLLM、SGLangrepo 已封存
