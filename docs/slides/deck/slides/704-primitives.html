三種原語：差在「誰決定用」

MCP Server 能提供的東西只有三類；記住誰握有觸發權，就記住了它們的用途與風險。

Tools
能做事的函式
誰決定何時用
模型
會有副作用（寫檔、寄信、訂房），所以客戶端通常要讓使用者先核准。
例　describe_excel
Resources
唯讀的資料來源
誰決定何時用
應用程式
不是「靜態」：可以用模板依參數動態產生，也能訂閱變化。
例　weather://forecast/{city}/{date}
Prompts
現成的提示詞模板
誰決定何時用
使用者
使用者主動挑一個來用（例如斜線指令），Server 把參數填進模板。
例　plan-vacation
你已經會的Tool 的 inputSchema 就是函式簽名；模型挑工具，像在候選動作上做一次分類。
怎麼讀：三角是工具、方塊是資料；每欄右側寫的是「誰有權在對話中觸發它」。
