子 agent 之間：只傳請求、只回摘要

每個子 agent 都從空白 context 開始；要共用的資訊，由 Supervisor 轉手寫進下一個請求。

Supervisor 的 context（它看到的全部）示意
使用者：週二跟 Ann 開會＋寄議程
→ schedule_event：週二下午跟 Ann 開會
← 摘要：已排週二 15:00–16:00
→ manage_email：通知 Ann 週二 15:00
← 摘要：已寄出
最終回覆：排好了，議程也寄出了
