Vibe Coding 不等於 AI 輔助工程

Karpathy 2025-02 提出；2026 年他已改稱 agentic engineering。本課轉述

可以拿去 demo
可以 commit 進 repo
Vibe coding
不看程式碼，只看結果能不能跑
AI 輔助工程
AI 寫、人審、人測
傳統加補全
人寫，AI 幫忙補全
你已經會的只看 loss 下降、不看預測結果一樣危險——程式能跑，不代表邏輯是對的。
AI 輔助工程的工作流
人：寫規格
AI：生成程式
人：審查、測試
能解釋，才 commit
Simon Willison：不 commit 任何自己無法向別人解釋清楚的程式碼。本課轉述
工具舉例：Cursor、Claude Code 這類程式碼 agent。
怎麼讀：由左到右，人審得越多、離 repo 越近；中間那格才是這門課要你做到的位置。
