Cypher：把要找的形狀畫出來

查詢就是一張 ASCII 小圖：圓括號是節點，方括號加箭頭是關係。

查詢（讀）：找出和韓立同門的人
MATCH (h:Person {name: '韓立'}) -[:MEMBER_OF]->(s:Sect) <-[:MEMBER_OF]-(p:Person) RETURN s.name, p.name
寫入：沒有才建，有就重用
MERGE (a:Person {name: '韓立'}) MERGE (b:Sect {name: '七玄門'}) MERGE (a)-[:MEMBER_OF]->(b)
同一個形狀，畫成圖
h：韓立
s：某個宗門
p：要找的人
回傳：厲飛雨、墨大夫 示意
MERGE 重跑也不會生出重複節點；批次寫入三元組一律用它，不用 CREATE。
Neo4j 2026.02 起，新資料庫預設 Cypher 25；模型學到的舊語法可能失效。
你已經會的Cypher 描述的是「要找的子圖形狀」，像 CNN 拿固定的 kernel 去比對——只是這裡比對的是結構，不是像素。
怎麼讀：先看左上的文字，再對照右邊的圖：同顏色的括號對應同顏色的方塊。
