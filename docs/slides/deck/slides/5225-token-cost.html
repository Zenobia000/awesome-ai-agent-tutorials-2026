值得用
可平行、廣度優先的研究類任務，資訊量超過單一 context。
不值得用
需要共享 context 的任務，或大多數寫程式任務。
你已經會的scaling law：多花算力換更好的結果。多 agent 同理，只是花的是 token。
怎麼讀：柱子越高，同一件事花的 token 越多；右邊是什麼情況下值得多花這筆錢。
