OpenAI 相容 API：一則請求長這樣

本地 Ollama 與多數雲端 API 都吃同一種格式。對話就是一個 messages 陣列，每個元素有角色與內容。

POST http://localhost:11434/v1/chat/completions { "model": "qwen3.5:9b", "messages": [ {"role": "system", "content": "你是簡潔的助理。"}, {"role": "user", "content": "用一句話解釋 token。"} ], "temperature": 0.6, "stream": true }

role ＝這句話是誰說的：system 是給模型的規則，user 是你，assistant 是模型之前的回覆。Ollama 不檢查 api_key，隨便填一個字串。

你已經會的像 PyTorch 換 device（cpu／cuda）：同一支程式，換 base_url 就換後端。
怎麼讀：左邊是真實的請求內容（黃底是對話本身）；右邊是同一支程式，只換 base_url，就能接本地或雲端的模型。
