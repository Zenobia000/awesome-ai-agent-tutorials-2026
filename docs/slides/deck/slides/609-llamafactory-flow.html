LLaMA-Factory：一個 yaml 走完整個流程

資料、設定、訓練、評估、合併匯出，各一步；評估看到過擬合就退回設定。

資料Alpaca 或 ShareGPT 的 JSON，在 dataset_info.json 登記
設定基座、template、lora_rank、學習率，全寫進一個 yaml
訓練只更新 A、B，定期存 adapter 檢查點
llamafactory-cli train
評估看 loss 曲線，用檢查點抽測對話，挑最好的
合併匯出把 adapter 併回基座，得到一個完整模型
llamafactory-cli export
過擬合：回到設定，減 epoch 或降學習率
你已經會的你寫過的訓練迴圈：資料 → 模型 → loss → 優化器 → 存 checkpoint，這裡整個收進一個 yaml。
怎麼讀：從左到右是一次完整微調；每個形狀底下是那一步你要準備的東西，最下方的弧線是失敗時退回的路。
