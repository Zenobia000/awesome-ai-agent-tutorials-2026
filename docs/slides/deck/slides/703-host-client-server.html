JSON-RPC：用 JSON 寫成「呼叫某個方法、帶參數、回結果」的訊息格式，每條線上傳的都是它。
怎麼讀：模型在 Host 裡；Host 為每個 Server 開一個 Client；下面兩段 JSON 是它們之間真正傳的訊息。
