評審校準：LLM 評審也要被驗證

LLM 評審就是個分類器：拿人工標註當標準答案，對不上就改它的提示詞。

評審 vs 人工：混淆矩陣
評審說 pass
評審說 fail
人工說 pass
人工說 fail
TP都說 pass
FN好的被攔下
FP壞的被放行
TN都說 fail
TPR好的被判對的比例
TNR壞的被抓出的比例
TPR＝TP ÷ (TP＋FN)　TNR＝TN ÷ (TN＋FP)
01人工標註當標準答案
專家逐條標 pass／fail，並寫下理由。
02對不上，就改評審的提示詞
把人工寫的理由當範例放進去，反覆改到兩邊一致。
03類別不平衡時，分開看 TPR、TNR
例如幾乎都是 pass：全猜 pass，整體一致率也很高。
你已經會的評審＝分類器，人工標註＝ground truth：看 precision、recall 和混淆矩陣，調提示詞像調超參數。
怎麼讀：左邊方格對照評審和人工，藍色是對的、朱紅是錯的；右邊三步是怎麼把評審調準。
