ReAct 原圖：Thought、Act、Obs

503 頁的三步，在論文裡就是這三個標籤，每一輪都照 Thought → Act → Obs 走。

Thought：想

先寫下推理：
要搜尋 Apple Remote。

Act：做（503 的 Action）

Search[…]＝呼叫搜尋工具
對應 tool_calls。

Obs：看（503 的 Observation）

搜尋結果寫回上下文
對應 role: tool 訊息。

圖的後半（已裁掉）還有第 3、4 輪。
最後一步 Finish[…] 結束迴圈，
就是 503 的 Final Answer。

同一題的其他做法（Standard、CoT、Act-only）都答錯，只有 ReAct 答對；原圖其餘三格沒有放進來。
來源：Yao et al.（2022）〈ReAct: Synergizing Reasoning and Acting in Language Models〉Fig. 1（p.2）中 (1d) 格的上半部（裁切，未改動內容），CC BY 4.0（arXiv:2210.03629）。裁切檔：assets/figures/m5/p-react-fig1-1d-crop.png。
怎麼讀：先看左邊三種顏色的框（一輪 Thought、Act、Obs），再順著箭頭到右邊，對回 503 頁的圓、三角、方。
