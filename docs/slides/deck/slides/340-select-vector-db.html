選型：向量庫

先問兩件事：資料多大、要不要內建混合檢索（BM25＋向量）。教學和原型用嵌入式，上線再換 server。

名稱型態內建混合檢索什麼時候選它授權
Chroma本課用docs.trychroma.com嵌入式／可自架本地版沒有（雲端版才有）教學、原型、單機 LabApache-2.0
Qdrantqdrant.techServer（Rust）有，server 端 RRF要上線，又要重度 metadata 過濾Apache-2.0
Milvusmilvus.io分散式 server有，內建 BM25＋RRF資料量極大，要水平擴展Apache-2.0
pgvectorgithub.com/pgvector/pgvectorPostgres 擴充沒有，要自己合併已經在用 Postgres，不想多一套 DBPostgreSQL License
Weaviatedocs.weaviate.ioServer（Go）有，但預設不是 RRF想要開箱即用的混合檢索BSD-3；部分企業功能另授權
OpenSearchdocs.opensearch.org搜尋引擎有，含 RRF要 Elasticsearch 生態又要免費 RRFApache-2.0
另外：FAISS 只是 ANN 函式庫，不是資料庫；Elasticsearch 的 RRF 要付費授權。　核實 2026-11-17
怎麼讀：先看第三欄：本課 Lab 用 Chroma，所以 BM25 與 RRF 要自己做；換成有內建混合檢索的庫，那段程式可以省掉。
