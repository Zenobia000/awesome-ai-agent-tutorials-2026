embedding：id 變向量，就是查表

token id 先變成 one-hot，再乘一張可學習的權重矩陣。乘出來的結果，剛好是矩陣的其中一列。

one-hot
E：V × d 權重矩陣
輸出：d 維向量
V ＝ 詞表大小
取出這一列

V 很大（約 5 萬到 15 萬），所以實作不會真的做矩陣乘法，而是直接按 id 取列。意思相近的 token，學出來的向量也會相近。

你已經會的nn.Embedding(V, d)：輸入整數 id，輸出 d 維向量。權重由反向傳播學出，和 CNN 學 filter 同理。
怎麼讀：從左邊的 id 出發。one-hot 只有一格是 1，它挑出矩陣的一列，那一列就是這個 token 的向量。
