GraphRAG 的四種查詢模式

官方文件目前列出四種；Basic 就是傳統向量 RAG，用來當對照組。

Basic
傳統向量 RAG（對照組）
問題找最像的 top-k 片段。
單點事實就夠用。
Local
從問題裡的實體切入
問具體對象的題：某個人、某件法寶的來龍去脈。
Global
讀社群報告，做 map-reduce
問全貌的題：主要的勢力、主題有哪些。
DRIFT
先看報告，再追問深挖
用社群報告得出初步答案與追問，再對追問做 Local 搜尋。
維護狀態：GraphRAG v3.3.0（2026-10-08）；README 寫明已「largely in maintenance mode」，只修 bug、不加新功能。面試講概念與取捨，比背套件 API 穩。
怎麼讀：由左往右，從最簡單的 Basic 到最複雜的 DRIFT；先判斷問題是「點」還是「全貌」，再選模式。
