選型：Agent 框架（一）

同一家族由低到高三層，再加三家模型廠商自己的 SDK。廠商 SDK 上手快，但常綁自家模型。

框架抽象層級什麼時候選它可換模型／狀態
LangGraphgithub.com/langchain-ai/langgraph低階：狀態圖確定性步驟和 agent 混合可；MIT；穩定版
LangChain create_agentdocs.langchain.com高階：agent＋middleware要能客製的 agent 外殼可；MIT；跑在 LangGraph 上
Deep Agentsgithub.com/langchain-ai/deepagents現成 harness：規劃＋子 agent長任務、要開箱即用可；MIT；Beta
OpenAI Agents SDKopenai.github.io高階：agent＋handoffsOpenAI 生態、語音、沙箱部分；MIT；仍是 0.x
Claude Agent SDKcode.claude.com把 Claude Code 當函式庫用要現成檔案、終端機工具與權限只能 Claude；MIT＋商業條款；Alpha
Google ADKgithub.com/google/adk-python中高階：agent＋流程＋圖Gemini／GCP、多種程式語言可；Apache-2.0
create_agent 和 Deep Agents 底下都跑在 LangGraph 上。　核實 2026-11-17
怎麼讀：紅字三列是本課主線，由低到高；下面三列是模型廠商的 SDK，先看「可換模型」那欄再決定。
