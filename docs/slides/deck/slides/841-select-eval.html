選型：評測（eval）工具

評測工具的差別在「評什麼」：RAG 的檢索品質、應用的單元測試，還是模型本身的能力。

工具評什麼什麼時候選它授權／狀態
LangSmith Evals本課用docs.langchain.com資料集＋評分器＋實驗比較已經用 LangSmith 追蹤商業 SaaS
Ragasgithub.com/vibrantlabsai/ragasRAG 指標：忠實度、相關性評 RAG 檢索與回答品質（模組三）Apache-2.0；GitHub 已搬家
DeepEvalgithub.com/confident-ai/deepevalpytest 風格的 LLM 測試想把評測寫進單元測試Apache-2.0
promptfoogithub.com/promptfoo/promptfoo比 prompt／模型＋紅隊測試在 CI 裡擋退步、做安全測試MIT；2026-03 被 OpenAI 收購
Inspect（UK AISI）github.com/UKGovernmentBEIS/inspect_ai模型與 agent 能力、安全基準評模型本身，而不是你的應用MIT
不管用哪個工具，最值錢的是你自己那份評測集（輸入＋參考答案）：工具可以換，考題要累積。　核實 2026-11-17
怎麼讀：先決定要評的是 RAG、應用流程還是模型本身，再挑對應的工具；紅字是本課 Lab 8 的組合。
