h = W·x ＋ (α/r)·B·A·x

ΔW = B·A：和 W 同形狀，秩 ≤ r。

起點：A 隨機、B 全為 0，所以一開始 ΔW = 0，模型和原本完全一樣。

r 是窄腰的寬度（Lab 用 8）；α/r 是旁路的放大倍率。

你已經會的A 壓成 r 維、B 再展開，就是 autoencoder 的瓶頸；W 就是你凍結 backbone 時的 requires_grad=False。
怎麼讀：從左邊的 x 出發，上路過凍結的 W，下路過窄腰 A→B，在「＋」相加成 h；訓練時只有朱紅色的兩塊會動。
