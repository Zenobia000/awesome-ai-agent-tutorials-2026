Lab 1：用 generator 接串流

generator 用 yield 一次交出一小片結果，呼叫端拿到就能立刻顯示，不必等整段生成完。

def stream_chat(messages): try: yield from _run(LOCAL, "qwen3.5:9b", messages) except (APIConnectionError, APITimeoutError): yield from _run(CLOUD, "deepseek-flash", messages) def _run(client, model, messages): resp = client.chat.completions.create( model=model, messages=messages, stream=True) for chunk in resp: piece = chunk.choices[0].delta.content if piece: yield piece
for piece in stream_chat(history): print(piece, end="", flush=True)
呼叫端：拿到一片就印一片

注意：切換若發生在串流中途，已經顯示的字收不回來，要另外處理。

怎麼讀：左邊是產生片段的 generator，右上是消費它的迴圈；右下對比不串流與串流：同樣的內容，使用者等待的樣子不同。
