微調是什麼

微調＝拿少量範例再訓練一下，把口吻、格式、術語練進權重裡；和 Prompt、RAG 的差別是「人變了沒有」。

教新同事的三種方法
給交辦單 → Prompt
每次交代清楚；人沒變（模組二）
給參考資料夾 → RAG
要用時再翻；人沒變（模組三）
送去受訓 → 微調
練到變成習慣；人變了，權重被改過（本章）
空心圓＝權重沒動，朱紅圓＝權重被改過
你可能已經見過
客服機器人永遠用同一種口吻、同一種格式回答
醫療、法律等領域的專用模型，滿口行內術語
公司自己的小模型，回答帶著公司的寫法和習慣
受訓教不了的
每天在變的資料 → 那是 RAG 的事
受訓要 GPU、要資料、要時間：先試 Prompt，不夠再微調
怎麼讀：三列由上往下，越往下越「深入」模型：前兩種只改輸入，第三種把東西練進權重；右邊是你見過的微調產品。
