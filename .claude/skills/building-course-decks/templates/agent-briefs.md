# Subagent 任務模板

把 〈〉 換掉再派。每份都要寫：讀什麼、只能寫哪些檔、怎麼自查、回報什麼。

## A. 素材地圖＋勘誤（階段 1；每 2 個模組一個 agent）
```
你在幫一門課找投影片素材。課綱：〈路徑〉，先讀〈模組 X、Y〉。
學生：〈已會什麼〉，但沒學過〈什麼〉。
要找的不是論文原文，而是別人系統整理好、有圖解、入門者看得懂的二手資料；我們參考其圖解結構自己重畫。
做法：每模組先寫 3–6 個「要講清楚的論點」→ 找用語、權威作者、常出好圖解的媒體 → 順連結與引用往外追。每論點 1–3 份，打不開或要登入的剔除。
輸出（只寫這兩檔）：sources/M〈X〉-〈名〉.md、sources/M〈Y〉-〈名〉.md
格式：論點清單／素材（標題—來源—URL（已核實日期）、適合程度、可借的圖解結構、搭橋）／事實核實（課綱每個版本號、API、模型名的查證＋出處）／投影片建議。
回報：論點數、素材數、和課綱不一致的項目。
```

## B. 章節生產（階段 4；每個編號前綴一個 agent）
```
工作目錄：〈deck 路徑〉。先完整讀 BRIEF.md，看 showcase 頁與 shots/ 截圖，讀 assets/base.css、draw.js。
你的前綴：〈N〉xx〈章名〉（清單在 BRIEF）。內容依據：../sources/product-facts.md（優先）、../sources/M〈N〉-*.md、課綱。
只寫自己前綴的檔；不改 assets/、index.html、build.py；不編數字。
每 3–4 頁：./shoot.sh 〈N〉 → contact.py 拼總覽 → 看圖修重疊、溢出、太空太擠。全部做完整章再看一輪。
回報：做了哪些檔、哪些頁還不夠好（具體哪裡）、偏離 BRIEF 之處與原因。
```

## C. Lab 實跑驗證（階段 6）
```
驗證投影片〈頁碼〉上的程式能不能跑、寫法對不對。在 scratchpad 用最小可重現環境實跑（uv 隔離環境、Docker、同 API 的小模型、小資料）；看產物而不只看 exit code；設定檔用工具自己的解析器驗，並對照官方 examples 逐鍵核對。
發現錯直接改投影片程式碼文字，改完截圖確認沒溢出。只動〈頁碼〉。
輸出 sources/lab-verification.md：驗證方式（實跑／對文件）、結果、改了什麼、未驗證的部分與原因。
```

## D. 實物素材蒐集（階段 7；論文／演講一個 agent，官方圖／logo 一個 agent）
```
先讀 BRIEF「實物層」。目標清單：〈每模組的經典論文、官方架構圖、套件〉——逐一核實編號、標題、圖號。
授權：看得到 CC BY／MIT 才標 direct；arXiv 預設授權或未標示一律 redraw（原圖放 _ref/ 只供重畫）；演講投影片多半 link。不要猜。
下載只存檔不執行；解壓放 scratchpad。數據頁要抄真實數字＋表號頁碼。
輸出（只寫這些）：assets/figures/figures-〈papers|docs〉.md 與圖檔。每項：檔案、來源、授權＋依據、建議用在哪頁之後、頁型、可用數據、給學生的一句話。logo 另列品牌條款。
回報：各授權類別數量、找不到或條款不允許的項目。
```
