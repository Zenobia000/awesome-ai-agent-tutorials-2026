# Runbook：主機磁碟快滿

> 服務：通用｜類型：runbook｜版本：-｜負責團隊：平台組｜更新：2026-02-14

## 警報門檻

- 80%：SEV3，上班時間處理。
- 90%：SEV2，值班立即處理。

## 處理步驟

1. `du -sh /var/log/hf/* | sort -h` 找出最大的目錄。
2. 應用日誌在主機上只保留 7 天，超過的可以刪。集中式日誌平台有 30 天副本，不會遺失。
3. 如果是 Kafka broker（`mq-b1`～`mq-b3`），**不要手動刪資料檔**，改用縮短 topic 保存時間的方式，並通知平台組。
4. 如果是資料庫主機，不要刪 WAL 檔，直接升級 SEV2 找平台組。
