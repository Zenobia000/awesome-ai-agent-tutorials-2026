# 正式環境存取申請 FAQ

> 服務：通用｜類型：FAQ｜版本：-｜負責團隊：資安組｜更新：2026-05-05

## 平常有權限嗎

沒有。所有工程師預設沒有正式環境主機與資料庫的寫入權限，`hfctl` 的讀取類指令（status、stats、lag）任何人都能用。

## 怎麼申請

1. 在內部入口填「ACC 存取申請單」，寫明原因、要碰的服務、預計動作。
2. 需要兩人核准：直屬主管與當週 SRE 值班。
3. 核准後權限有效 8 小時，到期自動收回。

## 緊急狀況

值班人員處理 SEV1／SEV2 時，可以用「破窗」（break-glass）權限立即取得存取，但事後 24 小時內要補申請單，
資安組會逐筆審查。

## 哪些動作一律要第二人核准

收單行切換、死信移轉、金鑰輪換、資料庫手動寫入。
