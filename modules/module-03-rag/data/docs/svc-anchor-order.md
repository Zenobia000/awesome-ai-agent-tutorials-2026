# anchor-order 訂單服務說明

> 服務：anchor-order｜類型：服務說明｜版本：v7.0.1｜負責團隊：交易組｜更新：2026-10-03

## 這個服務做什麼

anchor-order 管理訂單的完整生命週期：建立、付款、揀貨、出貨、完成與取消。

## 訂單狀態

```
CREATED → PAID → PICKING → SHIPPED → DONE
   │        │
   └────────┴──→ CANCELLED
```

- CREATED 狀態 30 分鐘內沒付款，自動取消並釋放庫存。
- PAID 之後、進入 PICKING 之前，會員可以自行取消，系統自動退款。
- 進入 PICKING 之後就不能自行取消，只能走退貨流程。

## 建立訂單時做的事

1. 向 harbor-stock 預留庫存（reservation），預留有效 20 分鐘。
2. 計算金額、折價券與運費。
3. 呼叫 tide-pay 付款，冪等鍵用 `order_id` 加上付款嘗試次數，例如 `ORD20261003001-2`。

## 錯誤碼

| 錯誤碼 | 意思 |
|---|---|
| ORD-2201 | 預留庫存逾時（harbor-stock 沒在 3 秒內回應） |
| ORD-2205 | 折價券已失效 |
| ORD-2310 | 訂單狀態不允許此操作，例如已出貨還想取消 |
