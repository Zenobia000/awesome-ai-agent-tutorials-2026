# 事故回顧：INC-2026-1008 搜尋結果大量消失

> 服務：reef-search｜類型：事故回顧｜版本：v4.2.0｜負責團隊：搜尋組｜更新：2026-10-12

## 摘要

2026-10-08 03:40 起約 5 小時，搜尋「耳機」「藍牙耳機」等詞幾乎找不到商品，影響約 18% 的搜尋流量。SEV2。

## 原因

前一天有人在同義詞檔 `synonyms_zh.txt` 加了一行「耳機 => 耳罩」，用的是單向替換語法 `=>`，
本意是雙向同義，結果所有「耳機」查詢都被改寫成「耳罩」。03:00 重建索引後生效。

## 處理

08:45 移除該行並執行 `hfctl search reindex --full`，09:30 恢復。

## 改善措施

1. 同義詞檔變更必須經搜尋組第二人審查。
2. 重建索引後自動跑 200 個熱門查詢的回歸測試，零結果的查詢比例超過 2% 就不切換別名。
