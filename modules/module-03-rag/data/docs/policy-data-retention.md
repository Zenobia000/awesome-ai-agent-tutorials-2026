# 資料保存政策

> 服務：通用｜類型：政策｜版本：2026 版｜負責團隊：資安組｜更新：2026-01-10

## 保存期限

| 資料 | 保存期限 | 依據 |
|---|---|---|
| 主機上的應用日誌 | 7 天 | 磁碟容量 |
| 集中式日誌平台 | 30 天 | 除錯需求 |
| 付款與請款紀錄 | 7 年 | 會計法規 |
| 會員個資（已刪除帳號） | 刪除申請後 30 天內清除 | 個資法 |
| 客服通話錄音 | 1 年 | 內部規定 |
| current-mq 事件 | 72 小時 | 只做傳遞，不做保存 |

## 個資刪除流程

會員申請刪除帳號後，lighthouse-auth 先停用帳號，30 天內由資料組從所有系統（含 sandbar 倉儲）清除。
付款紀錄因法規需保留 7 年，但會把姓名、電話、地址替換成匿名代碼。

## 日誌中禁止出現的資料

完整信用卡號、CVV、密碼、完整身分證字號。被發現要立即通報資安組，並從所有日誌系統清除。
