# Runbook：STK-310 庫存鎖競爭

> 服務：harbor-stock｜類型：runbook｜版本：v1.9.4｜負責團隊：交易組｜更新：2026-05-22

## 症狀

限量商品開賣時，下單失敗率升高，錯誤是 `STK-310`，前端顯示「目前購買人數過多」。

## 這是正常的嗎

開賣前 5 分鐘內 STK-310 比例在 10% 以下屬正常，代表鎖有在保護庫存不被超賣。
超過 30% 或持續超過 15 分鐘才需要處理。

## 處理步驟

1. 確認 Redis `rds-stock-01` 的延遲：p99 超過 20 毫秒代表 Redis 本身吃緊。
2. 熱門商品可以開啟「排隊模式」：`hfctl stock queue-mode on --sku <SKU>`，讓請求排隊而不是搶鎖。
3. 不要把鎖的 TTL 從 8 秒調長，鎖持有越久，排隊越長。
4. 活動結束後記得 `hfctl stock queue-mode off --sku <SKU>`。
