# 值班制度 FAQ

> 服務：通用｜類型：FAQ｜版本：-｜負責團隊：SRE｜更新：2026-08-01

## 誰要值班

所有後端工程師加入值班輪替，每週一 10:00 交接，一次一週。新人入職滿 3 個月後才排入，前兩次要搭配資深同事跟班。

## 嚴重度與回應時間

| 等級 | 定義 | 回應時間 |
|---|---|---|
| SEV1 | 核心功能（登入、下單、付款）全面無法使用，或資料遺失、資安事件 | 5 分鐘內回應，30 分鐘內通知主管 |
| SEV2 | 部分功能失效或明顯變慢，有替代方案 | 15 分鐘內回應 |
| SEV3 | 不影響使用者，或只影響內部 | 下一個工作天 |

## 呼叫工具

警報透過內部呼叫系統「浮標」（Buoy）發送到手機。SEV1 會同時打電話。5 分鐘沒確認會升級給備援值班。

## 值班補償

每週值班津貼 3,000 元；半夜（00:00～07:00）被叫起來處理 SEV1／SEV2，隔天可以補休半天。

## 事故回顧

SEV1 與 SEV2 結束後 5 個工作天內要寫事故回顧，格式：摘要、時間軸、根本原因、改善措施。回顧不追究個人責任。
