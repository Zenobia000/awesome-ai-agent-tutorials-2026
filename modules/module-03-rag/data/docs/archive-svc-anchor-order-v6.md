## 訂單狀態

```
CREATED → PAID → PICKING → SHIPPED → DONE
   │
   └──→ CANCELLED
```

- CREATED 狀態 60 分鐘內沒付款，自動取消並釋放庫存。
- 只有 CREATED（尚未付款）可以由會員自行取消。付款之後要取消，必須聯絡客服人工退款。
