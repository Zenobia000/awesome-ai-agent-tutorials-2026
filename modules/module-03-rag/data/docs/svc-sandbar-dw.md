# sandbar 資料倉儲說明

> 服務：sandbar-dw｜類型：服務說明｜版本：v1.3｜負責團隊：資料組｜更新：2026-04-18

## 這是什麼

sandbar 是海風的分析用資料倉儲，給營運報表與資料科學使用，不支援線上交易查詢。

## 資料同步

- 每天 04:00 從各服務的 PostgreSQL 唯讀副本抽取前一天資料（ETL），約 1.5 小時完成。
- 營運早報 08:30 寄出，所以 ETL 在 07:30 前沒完成就會發 SEV3 警報。

## 個資遮罩

- 手機號碼只保留後 3 碼，例如 `09xx-xxx-123`。
- Email 只保留網域。
- 信用卡號一律不進倉儲，只存卡別與末 4 碼。
- 想看未遮罩資料要走個資調閱申請，資安長核准，有效 3 天。

## 存取方式

用公司帳號登入 SQL 查詢介面，查詢單次逾時 10 分鐘，結果超過 100 萬列要改用匯出功能。
