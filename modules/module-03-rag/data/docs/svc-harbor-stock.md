# harbor-stock 庫存服務說明

> 服務：harbor-stock｜類型：服務說明｜版本：v1.9.4｜負責團隊：交易組｜更新：2026-05-20

## 這個服務做什麼

harbor-stock 記錄每個商品在每個倉庫的可售數量，並提供「預留」功能，避免同一件商品被賣兩次。

## 預留機制

- 下單時預留，預留有效 20 分鐘；付款成功轉成正式扣庫存，逾時或取消則自動釋放。
- 同一商品同時被多人搶購時，用 Redis 分散式鎖保護，鎖的 TTL 是 8 秒。
- 搶不到鎖會重試 3 次，每次間隔 200 毫秒，仍失敗就回 `STK-310`。

## 錯誤碼

| 錯誤碼 | 意思 |
|---|---|
| STK-301 | 庫存不足 |
| STK-310 | 鎖競爭失敗（熱門商品搶購時常見） |
| STK-320 | 倉庫代號不存在 |
