# reef-search 商品搜尋服務說明

> 服務：reef-search｜類型：服務說明｜版本：v4.2.0｜負責團隊：搜尋組｜更新：2026-06-30

## 這個服務做什麼

reef-search 提供海風購的商品搜尋與自動完成，底層是 OpenSearch 2.13 叢集，5 個資料節點。

## 索引更新

- 每天 03:00 做全量重建索引，約需 40 分鐘，用別名（alias）切換，搜尋不中斷。
- 商品價格與庫存變動透過 current-mq 即時更新，延遲通常在 5 秒內。

## 中文斷詞與同義詞

- 使用 IK 斷詞外掛，自訂詞庫放在 `reef-dict` 儲存庫。
- 同義詞檔 `synonyms_zh.txt`，例如「手機殼, 保護殼」「行動電源, 充電寶」。
- 改同義詞後需要重建索引才會生效，所以要等隔天 03:00，或手動執行 `hfctl search reindex --full`。

## 效能目標

- 搜尋 API p95 延遲 < 120 毫秒。
- 自動完成 p95 < 40 毫秒。
