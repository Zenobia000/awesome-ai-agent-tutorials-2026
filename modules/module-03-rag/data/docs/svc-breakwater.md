# breakwater API 閘道服務說明

> 服務：breakwater｜類型：服務說明｜版本：v2.8.3｜負責團隊：平台組｜更新：2026-09-02

## 這個服務做什麼

breakwater 是海風購所有對外 API 的唯一入口。手機 App、網站前端、合作夥伴的呼叫都先進 breakwater，
由它做驗證、限流、路由，再轉給後面的 anchor-order、tide-pay、reef-search 等服務。
內部服務之間互相呼叫不經過 breakwater，走服務網格。

## 限流規則

- 一般 API 金鑰：每分鐘 600 次請求，超過回 `BW-429`。
- 合作夥伴金鑰（partner tier）：每分鐘 3,000 次。
- 登入相關路徑 `/v1/auth/*`：每個 IP 每分鐘 30 次，防止撞庫攻擊。
- 限流計數存在 Redis 叢集 `rds-gw-01`，計數視窗為 60 秒滑動視窗。

## 逾時與熔斷

- 轉發到上游的預設逾時是 15 秒，設定鍵 `upstream_timeout_ms`。tide-pay 例外，設為 30 秒，因為收單行回應慢。
- 熔斷器：同一上游在 20 秒視窗內錯誤率超過 50%，熔斷器打開，直接回 `BW-503`。
- 打開 30 秒後進入半開狀態，放 5% 流量試探，成功率回到 95% 以上才完全關閉。

## JWKS 快取

breakwater 會驗證 lighthouse-auth 簽發的 JWT，公鑰從 JWKS 端點取得並快取。
快取時間設定鍵 `jwks_cache_ttl`，2026 年 6 月事故後從 6 小時改為 10 分鐘（見 INC-2026-0607 事故回顧）。

## 錯誤碼

| 錯誤碼 | 意思 | 常見原因 |
|---|---|---|
| BW-401 | 未帶憑證或憑證無效 | token 過期、簽章驗不過 |
| BW-429 | 超過限流 | 客戶端重試沒有退避 |
| BW-503 | 上游熔斷中 | 後端服務大量錯誤 |
| BW-504 | 上游逾時 | 超過 `upstream_timeout_ms` |
